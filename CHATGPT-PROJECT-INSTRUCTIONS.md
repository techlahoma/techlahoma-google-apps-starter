# ChatGPT Project Instructions

Use this repository as the baseline when creating a new project unless the user
selects another scaffold.

Start with `PROJECT.md`, then read `AGENTS.md` and active instructions under
`.starter/addenda/`.

When starting from an existing repository:

- inspect its current instructions, status, and configuration first;
- merge this baseline additively;
- preserve stronger or project-specific rules;
- merge ignore patterns instead of replacing them;
- do not overwrite the README, `PROJECT.md`, `AGENTS.md`, `.gitignore`,
  `.editorconfig`, pull-request template, toolchain, license, remote,
  visibility, or CI configuration wholesale;
- surface material conflicts for review.

Never fabricate data, results, dates, evidence, commands, or resolved unknowns.
Keep important state in repository files, default application architecture to
Scale-to-zero and Durable, and preserve unrelated work.

This baseline does not authorize creating a remote repository, staging,
committing, pushing, opening or changing a pull request, deploying, publishing,
merging, sending messages, or changing repository settings. Report local
changes, commits, pushes, deployments, and live verification as distinct states.
