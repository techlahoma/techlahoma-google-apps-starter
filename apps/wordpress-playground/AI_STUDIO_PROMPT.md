# AI Studio prompt: hosted WordPress workshop

- `Tease:` Finish the hosted page while keeping WordPress and MCP on the participant's side.
- `Lede:` Use this prompt with the standalone project generated by the monorepo's export script, not an assumed monorepo root import.
- `Why it matters:` The root starter launches a different app, and a cloud agent cannot connect directly to the attendee's loopback bridge.
- `Go deeper:` The source implementation and evidence live in [the meetup repo's workshop workspace](https://github.com/techlahoma/techlahoma-google-apps-starter/tree/feat/wordpress-playground-workshop/apps/wordpress-playground).
