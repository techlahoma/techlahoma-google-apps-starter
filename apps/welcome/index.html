Google App Starter

One repo.
As many small apps as the demo needs.

Shared TypeScript tooling, app-local Firebase configuration, and explicit agent-safe commands. Create every experiment under apps/ without disturbing the others.

01

Create an app

bun run app:create plan --name my-app --title "My App"
02

Build locally

bun run --cwd apps/my-app dev
03

Grow deliberately

Add Firebase or Cloud Run only after that app actually needs shared state.

Static by default · app-scoped config · one project per environment
