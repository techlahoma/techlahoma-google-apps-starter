# Intro to Google Developer Group — public event hub

- `Tease:` Start here at the Techlahoma × GDG Tulsa workshop.
- `Lede:` This is the attendee-safe home for the public starter, copy-ready Antigravity prompts,
  community links, and the rules that make the event welcoming.
- `Why it matters:` Every link on this page should open without access requests, and every build can
  begin from the same known-good repository.
- `Go deeper:` Clone the starter, choose one prompt, and build a new app under `apps/`.

- **Event:** Intro to Google Developer Group
- **Workshop date:** August 6, 2026
- **Presented by:** Techlahoma with GDG Tulsa

## Build something

1. [Open the repository](https://github.com/techlahoma/techlahoma-google-apps-starter).
2. Follow the [five-minute local start](../../README.md#clone-and-start).
3. Open the cloned folder in Antigravity.
4. Paste one of the [one-shot demo prompts](antigravity-one-shot-prompts.md).
5. Keep every generated demo in its own `apps/<slug>/` directory.

The prompts finish at a verified, running local URL. They do not authorize an agent to commit, push,
deploy, authenticate an account, provision cloud resources, or delete anything.
