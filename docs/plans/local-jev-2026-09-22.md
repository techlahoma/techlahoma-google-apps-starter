# Local Jev secret demo

- `Tease:` A fifth experiment, off the menu.
- `Lede:` Add a local, real-time slop detector at `#local-jev` using SemIf’s browser inference setup. Keep the four visible workshop stages unchanged.
- `Why it matters:` Attendees can see a semantic decision update while scrolling or editing, without generating a chat answer or training a model.
- `Go deeper:` See the app’s SemIf provenance notice and verification below.

## Design

- Primary interaction: score the sample post crossing the center of a scrollable feed. All feed content is authored synthetic workshop material.
- Secondary interaction: edit a paragraph or the judging criterion and rescore after a 650 ms pause.
- One active model operation at a time. Drop obsolete pending inputs and ignore obsolete results. Display no score before an actual result.
- Default MiniCPM5 2B; optional smaller Qwen3 0.6B. Explicit download action, on-device decisions, stop/unload, visible errors and measured latency.
- Display `Slop` / `Clear` probabilities normalized over those choices. Explain that these are uncalibrated style judgments and do not identify AI authorship.
- Product name requested by Sam: Local Jev. Attribution identifies SemIf and states independence from Jev/TypeSafe.
- The route is hidden from navigation, not access-controlled. No secrecy guarantee for public source or a shared URL.
